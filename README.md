# Kauzariyya Arts Festival

The application now uses a Go backend and a React frontend. Go serves the compiled React application, the REST API, static assets, admin sessions, uploads, and either PostgreSQL or the local JSON fallback.

## Requirements

- Go 1.22 or newer
- Node.js 20 or newer

## Run locally

```bash
npm install
npm run build
go mod download
go run ./cmd/server
```

Open `http://localhost:8000`. The admin dashboard is at `http://localhost:8000/admin`.

The default development admin password is `123`. Set `ADMIN_API_KEY` before deploying.

## Project structure

- `src/main.jsx` — React application
- `assets/react/app.js` — production frontend bundle generated by Vite
- `cmd/server/main.go` — Go HTTP server, routing, sessions, and page rendering
- `cmd/server/api.go` — Go REST API and validation
- `cmd/server/store.go` — PostgreSQL and JSON data access
- `web/index.html` — HTML shell rendered by Go
- `database/runtime-data.json` — local fallback data
- `database/schema.sql` and seed files — PostgreSQL setup

## Configuration

The server reads these environment variables directly or from `.env`:

```env
APP_ADDR=:8000
ADMIN_API_KEY=replace-with-a-long-random-password
SUPABASE_DB_HOST=your-db-host
SUPABASE_DB_PORT=5432
SUPABASE_DB_NAME=postgres
SUPABASE_DB_USER=postgres
SUPABASE_DB_PASSWORD=your-password
SUPABASE_DB_SSLMODE=require
```

PostgreSQL is optional. When the database variables are absent or the connection cannot be established, Go uses `database/runtime-data.json`. For Supabase, run `database/schema.sql`, `database/seed.sql`, and `database/seed-college-students.sql`, then use the Session Pooler connection details.

Uploaded team images are written to `assets/uploads`, which must be writable by the server process.

## Routes

Public pages use clean URLs:

- `/`
- `/scoreboard`
- `/schedule`
- `/participants`
- `/review`
- `/admin`

The API is available at `/api?resource=...`:

- `GET status`, `scoreboard`, `schedule`, `participants`, `results`, `settings`
- `POST reviews` for public review submission
- `POST admin-login`; `GET` or `DELETE admin-session`
- Protected score, team, program, participant, student, review, settings, schedule-block, result, and team-image operations

Protected requests use the secure admin session cookie. Server-to-server integrations can send `X-Admin-Key`.

## Production build

Build the React bundle before compiling or starting Go:

```bash
npm ci
npm run build
go build -o kauzariyya ./cmd/server
./kauzariyya
```

Run the binary with the project directory as its working directory so it can find `web`, `assets`, and `database`.
